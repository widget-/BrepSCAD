## Module declarations update

- Added `MODULE_DECLARATION`, `PARAM_LIST`, and `PARAM` to the lossless CST.
- User modules now support positional and named parameters, defaults that can
  reference earlier parameters, recursion, forward declarations within a block,
  and nested module definitions scoped to their enclosing module.
- Replaced the evaluator's flat variable map with a scope stack. Module and
  loop locals shadow caller values and restore on exit, while module bodies
  still read caller variables (OpenSCAD's dynamic scoping).
- Added `children()`, `children(n)`, and `$children`. Children are evaluated in
  the caller's scope at the transform where `children()` appears, with `$`
  arguments from the module call re-applied.
- Module call arguments are merged into the returned part parameters, so
  call-site values stay editable in the properties panel.
- Test suite: 186 tests passing (up from 164). New coverage lives in
  `crates/scad-eval/tests/modules.rs` and `crates/scad-syntax/tests/roundtrip.rs`.

## Function declarations update

- Added `FUNCTION_DECLARATION`, `CALL_EXPR`, and `CONDITIONAL_EXPR` to the CST,
  plus `?` tokens and ternary parsing.
- User functions support positional and named parameters, defaults that can
  reference earlier parameters, recursion, forward declarations within a block,

- Function calls work anywhere an expression is accepted, including module

  `max`, `norm`, `cross`, `len`, `concat`, `is_num`, `is_bool`, `is_list`.
- Added lazy conditional expressions (`? :`); only the selected branch runs.
- Test suite: 207 tests passing. New coverage lives in
  `crates/scad-eval/tests/functions.rs` and
  `crates/scad-syntax/tests/roundtrip.rs`.

## Collections update

- Added `INDEX_EXPR`, `FOR_EXPR`, `IF_EXPR`, and `LET_EXPR` to the CST.
- Postfix indexing works on vectors and matrices, including chained access such
  as `m[1][0]`.
- `let (a = ..., b = ...) expr` binds sequential locals for one expression
  without leaking them.
- List comprehensions support multiple bindings, nesting, `if` filters with
  optional `else`, and `let`. Nested `for` comprehensions flatten; a
  vector-valued body becomes a matrix row.
- Test suite: 227 tests passing. New coverage lives in
  `crates/scad-eval/tests/collections.rs` and
  `crates/scad-syntax/tests/roundtrip.rs`.

## Extrusion options update

- `linear_extrude` accepts `center` as a named or second positional argument.
  The default remains BrepSCAD's centered Z placement; `center=false` starts at
  `z = 0`, and `center=true` overrides legacy centering.
- `offset(r = ..., chamfer = true)` uses bevel joins; `delta` offsets remain
  miter joins, and `chamfer` with `delta` is rejected.
- Test suite: 231 tests passing. New coverage extends
  `crates/scad-eval/tests/extrusions.rs` and
  `crates/scad-eval/tests/legacy_centering.rs`.

## Strings and includes update

- Added `include` and `use` statements with quoted or angle-bracket paths and

## Planning

The compatibility matrix is now much smaller. The next work should stay
focused on features that unlock real files:

1. **Language**
   - Library search paths for angle-bracket includes.
   - Heterogeneous lists and vector slices.
   - Remaining built-ins (`search`, `lookup`, `rands`).
2. **2D and extrusion**
   - `linear_extrude` `twist`, `scale`, and `slices`.
   - `offset` `$fn` sampling controls and profile smoothing.
   - Negative-side `rotate_extrude` profiles.
3. **Kernel robustness**
   - Test Truck PRs #137 (revolved seam hints), #110 (coplanar/degenerate
     divisions), and #134 (untouched-face classification) against master.
   - Keep the vendored fallible-face patch until a release includes an
     equivalent fix.
4. **Compatibility gaps**
   - `hull` and `minkowski` via an internal mesh fallback.
   - `color`, `projection`, `surface`, and import/export/file I/O.
5. **Product surface**
   - Native file dialog and recent-file handling.
   - Selected-part highlighting and overlapping-part cycling.
   - Export, undo/redo, and session persistence.
6. **Later**
   - BOSL2-style native intrinsics such as rounded cuboids.
   - OCCT and SolidCore adapters behind the capability API.
