## Analytic cylinder fix

The earlier polyhedral-cylinder workaround was removed. The analytic cylinder
primitive is back.

The actual regression was in tessellation of boolean-derived analytic results,
not in the boolean itself. The fix tracks solids produced by booleans and
propagates that marker through transforms. Only boolean-derived solids use a
coarser display tessellation tolerance (`0.05`); exact primitives keep the
requested tolerance. This preserves the analytic B-rep benefits and keeps the
release suite green.

## Opengrid kernel investigation

The opengrid failure is independent of the analytic cylinder: its bin body is
built from polyhedral `prism_stack()` solids.

Work done on `wip/opengrid-kernel-fallbacks`:

- Boolean errors now include module, source range, and child modules.
- The failure was reduced to overlapping cubes.
- Master shapeops face division returns non-simple wires for that case.
- The WIP branch now tolerates non-simple/open boolean faces through:
  - shapeops face division
  - shell `mapped` / `try_mapped`
  - `Solid` mapping and transforms
  - meshalgo polygon tessellation
  - a final compound-union fallback

Results:

- Minimal overlapping-cube union and difference render.
- `snap_outer_shell()` renders by itself.
- The 1x1 opengrid bin gets past the earlier union failures and reaches a later
  difference in `modules/snap.scad`.
- A standalone `snap_grid()` probe still reaches
  `bad arguments for polyhedron: expected a number`, but that probe needs to use
  the exact arguments supplied by `opengrid-bin.scad` before it is treated as
  the real failure.
- The 2x2 bin has not been rechecked after the latest fallbacks; earlier it
  exceeded the 90-second release timeout.

## Risks

The WIP fallbacks deliberately weaken shell validation:

- open and non-simple boolean results are allowed through mapping/tessellation
- compound unions can stand in for unions shapeops cannot fuse

The release test suite is green, but these changes need review before merging
to `main`, especially around B-rep semantics and downstream bounds/volume
operations.
