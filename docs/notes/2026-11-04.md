## Root cause

`Loops::add_edge` splits an existing boundary wire when an intersection curve
touches it, and assigns the split halves `And`/`Or`. When the intersection
curve runs *along* the face boundary instead of crossing it, the face is still
one whole pre-face, but it inherits the curve's status. The pipeline then never
ray-casts it, so internal cell walls whose sides lie inside the hull are kept.

The fix has two halves:

- `BoundaryWire` now carries a `boundary` flag, set for the face's own
  boundaries and preserved through `split`/`inverse`. Intersection wires stay
  non-boundary.
- `divide_one_face` detects the case: one pre-face, its only chunk is a boundary
  wire with a known `And`/`Or` status, and its projected area equals the face
  outline. Such a pre-face is reset to `Unknown`, so the existing interior-point
  ray cast decides. The outline projection is only done for that candidate, not
  for every face.

## Caveat for reduced cube tests

BrepSCAD centres `cube()` by default; OpenSCAD does not. Use
`--legacy-centering` when comparing cube-based reductions, or all cubes are
displaced by half their size and the comparison is meaningless.
